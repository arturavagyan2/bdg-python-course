# Lesson 01 · Script route
Each .py file contains its complete task above the coding area. Keep this folder as your working copy; never type Python into this README.

| Task | File | Time |
|---|---|---|
| A · Invitation | invitation.py | 10 min |
| B · Text or calculation? | prediction.py | 8 min |
| C · Repair and check | repair.py | 12 min |

Run from this folder, for example `python3 invitation.py` (Windows: `py invitation.py`). Or use **Run Python File in Terminal** in VS Code. The terminal command starts Python and tells it which saved file to read; it is not Python source code. B is runnable. C intentionally raises SyntaxError until you repair it. A, D and E begin with comments only and produce no output yet; this is expected.

Complete the worked/guided examples in teaching.ipynb first; the instructor can demonstrate them using demo/ scripts if Jupyter is unavailable. Full task overview: [practice.md](../practice.md).
