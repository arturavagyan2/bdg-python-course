# Fictional shop messages · synthetic model proposals
**Open after recording your own rule predictions.** These four responses were invented for this lesson as discussion material. They are not recorded model outputs, not results of a live run and not an answer key. Some claims deserve disagreement. No account, payment, credentials or network is required.

The imagined request was: “Suggest Refund queue, Delivery queue or Human review based on what the sender appears to need. Explain briefly and point out ambiguity.” This semantic request differs from the Python classifier's literal substring policy. Agreement is not proof; disagreement needs a trace and a reading of the message.
