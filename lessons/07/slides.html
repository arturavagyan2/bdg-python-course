A loop can build a new list

Example.py
prices = [3, 6, 9]
reduced = []
for price in prices:
    reduced.append(price - 1)
print(reduced)
Output
[2, 5, 8]

W3. Which list changes? Check prices too.

The same calculation in a comprehension

Example.py
prices = [3, 6, 9]
reduced = [price - 1
           for price in prices]
print(reduced)
Output
[2, 5, 8]

For each price, keep price - 1. W3b. Use a loop when several steps read more clearly.

A final if chooses which values to keep

Example.py
prices = [3, 6, 9]
small = [price for price in prices
         if price <= 6]
print(small)
Output
[3, 6]

Would changing <= to < keep 6? Predict before the reveal.
