One entry per distinct name

Example.py
arrivals = ["Mia", "Noah", "Mia"]
present = set(arrivals)
print(sorted(present))
print(len(present))
Output
['Mia', 'Noah']
2

W1. sorted gives predictable display. A set itself has no defined order or indexes.

Who attends either workshop?

Example.py
morning = {"Ada", "Bo"}
evening = {"Bo", "Cy"}
print(sorted(morning.union(evening)))
Output
['Ada', 'Bo', 'Cy']

Union includes either group. Bo needs one badge, even though Bo attends both.

Both groups or one group only?

Example.py
morning = {"Ada", "Bo"}
evening = {"Bo", "Cy"}
both = morning.intersection(evening)
only = morning.difference(evening)
print(sorted(both))
print(sorted(only))
Output
['Bo']
['Ada']

Intersection: both. Difference: start with morning and exclude evening. W2.

A key identifies a value

Example.py
stock = {"pens": 8, "pads": 3}
print(stock["pens"])
stock["pens"] = 6
stock["clips"] = 10
del stock["pads"]
print(stock)
Output
8
{'pens': 6, 'clips': 10}

W3. Product name: key. Count: value. Reusing a key replaces its value.

Example.py
